# SceneQ

> Your all-in-one entertainment companion to discover, book, and experience the best movies, concerts, comedy shows, and live events in your city — without ever waiting in line.

---

## Project Structure

```
SceneQ/
├── SceneQ/          # Frontend — React + Vite + Tailwind CSS v4
└── backend/         # Backend — Bun + TypeScript
```

---

---

## Getting Started

### Frontend

```bash
cd SceneQ
bun install
bun dev
```

Runs on **http://localhost:5173**

### Backend

```bash
cd backend
bun install
bun run index.ts
```

---

## Available Scripts

### Frontend

| Command       | Description              |
| ------------- | ------------------------ |
| `bun dev`     | Start dev server         |
| `bun build`   | Build for production     |
| `bun preview` | Preview production build |
| `bun lint`    | Run ESLint               |

### Backend

| Command            | Description              |
| ------------------ | ------------------------ |
