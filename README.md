# SceneQ

## SceneQ is your all-in-one entertainment companion to discover, book, and experience the best movies, concerts, comedy shows, and live events in your city—without ever waiting in line.

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.4.2. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
